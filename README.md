# Spanish Tourism Habits: Statistical Analysis & Inference (2015-2025)

This repository contains a comprehensive statistical analysis exploring how education levels influence tourism consumption and mobility habits in Spain. 

**Tech Stack:** `R` (Tidyverse, ggplot2, lubridate, dplyr).

## About the Project
This study processes real microdata from the Spanish National Statistics Institute (INE), handling a dataset of **669,490 observations and 117 variables** spanning a decade. 

Key features of this codebase include:
* **Data Wrangling:** Big Data cleaning, transformation, and structuring using the Tidyverse ecosystem.
* **Exploratory Data Analysis (EDA):** Advanced data visualization including time series, heatmaps, and violin plots to identify underlying patterns.
* **Statistical Inference:** Rigorous hypothesis testing and linear regression models to isolate demographic and economic biases from educational trends.
